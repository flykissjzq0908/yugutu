# 待考虑方案（暂不实现）

## 1. 箭头线拖入自动吸附成真连线

状态：已决定不实现，分析结论保留到后续优化计划（2026-08-31 确认）。

目标：左侧“箭头线”拖入画布后，落在节点/端口附近自动吸附成真连线（bone-edge），现有端口拖拽连线方式保留。

规则草案：

1. 落点距某个节点端口 ≤ 24px，且另一端 80px 内存在其他端口时：删除箭头线节点，直接生成 A→B 真连线。
2. 不满足吸附条件时：保留为自由箭头线节点，可拉伸、拖动。
3. 吸附转换走 `assignEdgeHierarchy`，同步写入 `parentId/order/level`，与严格层级校验一致。
4. 转换操作放入单个 batch，保证一次撤销还原。
5. 吸附判定使用几何距离，不依赖端口可见性（端口默认隐藏、悬停显示）。

风险/注意：

- 阈值需要真机调优，避免无法摆放自由线段。
- 一次拖入只能确定一个端点，另一端通过“附近最近端口”补齐，否则降级为自由线。
- 必须保证“真连线”只有 bone-edge 一个身份，避免与箭头线节点数据重复。

结论：

- 当前组件库实际没有 arrow-line 项，做此功能需先补组件，范围比本方案更大。
- 自动转换存在节点/连线身份冲突、吸附误连、交互误触、保存导入与撤销回归面大的弊端。
- 替代方案按成本排序：先把 arrow-line 作为自由标注箭头加入组件库 → 增强端口拖线发现性（端口半可见/拖线提示）→ 仅做“箭头线末端吸附显示为连线”且保留箭头线身份，不生成 bone-edge。
