# 鱼骨图版本记录

## V4.0（2026-09-11）定稿版本

- 当前版本：鱼骨图 V4.0（定稿），V3.1 及之前历史节不回改
- 定稿范围：新增旧 Raphael 渲染器引擎、按层级重建布局、legacyLine 几何持久化与拖动挂点距离传播
- Git 标签：`v4.0`

### V4.0 新增/收口

- 新增“按层级重建布局”按钮：不读取 `positions` 位置，按数据上下级关系用旧 Raphael 算法重建鱼骨图
- 引入旧 Raphael 渲染器引擎，默认优先使用，失败时回退纯算法；两种方案可安全结合
- 旧算法导出节点文字坐标、线段 `x1/y1/x2/y2`、层级、顺序、角度、鱼头鱼尾鱼干位置
- 新增 `legacyLine` 几何数据：写入、保存、载入；用户编辑这类边时清除 `legacyLine` 恢复普通边
- 最大支持到第 4 级鱼刺
- 拖动节点时挂点距离传播：保存 `legacyAnchorDistance`，新挂点 = 父线起点 + 父线单位方向 × 原距离，父线变短时临时钳制且不覆盖原距离
- 子线只更新 `x1/y1`，保持 `x2/y2`、子节点位置、父子关系与 `legacy-line` connector
- 文字测量固定默认值；箭头与鱼头鱼尾按新方式绘制，保证位置一致

### 回归

- 旧算法与 X6 同一文档（`docId=2727f488dc26-4e26-986e-1a6578edd5c5`）线段坐标误差 `0.0`，保存后重新载入一致
- 拖动跟踪：父线长度 `300.1666 → 219.3376`，挂点距离 `100.3444 → 100.3443`，比例 `0.3343 → 0.4575`，证明是距离固定而非比例固定
- `npm run build`、`vue-legacy-line-persistence.js`、`vue-angle-layout.js`、`vue-hierarchy-noop.js`、`vue-edge-refresh-converge.js` 通过
- 已知测试问题：`vue-rebuild-layout.js` 的 `presetOk` 用例先 Undo 后断言导致失败，不影响当前渲染器布局

## V3.1（2026-09-10）定稿版本

- 当前版本：鱼骨图 V3.1（定稿），V3.0 及之前历史节不回改
- 定稿范围：新增按角度刷新布局；修正无位置数据初始化布局和交叉问题；Oracle 模式启动时跳过自动建表
- Git 标签：`v3.1`

### V3.1 新增/收口

- 通用鱼刺设置增加“斜线角度”和“按角度刷新鱼骨图”
- `layoutByAngle()` 按层级、order 奇偶和鱼头方向重算线段；只在用户主动刷新时执行
- 一级、三级保持上下半平面；二级、四级保持左右半平面；角度候选越界时镜像回半平面
- 无位置数据初始化使用同级锚点比例 `(order + 1) / (兄弟数 + 1)`
- 无位置数据初始化按层级和 order 奇偶安排子节点，顶部鱼刺子节点反向展开，避免同级线段交叉
- 无位置数据载入不再自动调用角度刷新
- Oracle 模式启动时跳过 `hl_ygt` / `hl_ygtmx` 自动建表，使用现有数据库表

### 回归

- `vue-angle-layout.js`：角度和上下左右边界通过
- `vue-legacy-ratio.js`：无位置锚点比例为 `0.25 / 0.5 / 0.75`
- `vue-hierarchy-noop.js`：`nodeDiff: []`、`edgeDiff: []`
- 无位置布局相交检测：`pairs: []`

## V1.0（2026-09-04）当前版本基线

- 基线提交：`v1.0`，分支 `main`，已同步 GitHub `origin/main`
- 稳定快照：`.rollback/stable-line-refresh-20260903`
- 本轮改动快照：`.rollback/pre-edge-refresh-converge-20260903`
- 基线依据：`docs/HANDOFF.md` 第 1 至 19 节
- 用途：作为鱼骨图 V1.0 功能基线；后续版本只在本文件新增版本节，不回改本节

### 技术架构

- Vue 3 + Vite 前端，AntV X6 3.1.8 画布引擎，jsPDF 本地离线资源
- FastAPI 后端，JWT Bearer 鉴权，SQLite / PostgreSQL / Oracle 存储
- 前端接口地址由 `vue/dist/config.js` 的 `window.YGT_API_BASE` 配置
- 构建产物支持根路径与 `/vue/ygt/` 子路径部署

### 图形与画布

- 鱼骨骨架：鱼头、鱼尾、鱼干/中脊
- 业务节点：一级鱼刺 group、二级及以下 bone、原因分组、文本框、图片、连接点磁点
- 7 套鱼形预设，支持左右朝向切换
- 模板：空骨架、经典六原因、根因分析
- 图片背景、图片节点、超链接

### 编辑与交互

- 组件库拖拽、节点连线、双击编辑文字
- 属性面板：颜色、字号、字重、填充、边框、线宽、透明度
- 批量样式、对齐与分布
- Undo / Redo、历史面板、复制、剪切、粘贴、快速复制、删除、清空
- 空格平移、方向键微调、Ctrl+A 全选、Ctrl+滚轮缩放
- 拖拽吸附、右键菜单、快捷键说明浮层
- 通用鱼刺设置：按层级设置线条与节点控件并随文档保存
- 鱼头文字默认跟随填充色，支持横向 / 竖向文字
- 自研取色弹层：色块、Hex、RGB、确认后应用

### 端口、连线与箭头

- 四向端口：left / right / top / bottom
- 端口自动重锚与手动方向覆盖，加载时自动归一化
- `bone-edge` 直线连线，支持节点到节点、节点到线体、线体到线体
- 连线起点、终点可拖拽，支持吸附线段、吸附端口、拖成自由点
- Alt+单击线体添加连接点，双击鱼干添加连接点
- 预览 / 导出时隐藏连接点并补齐线段空隙
- 箭头按线宽精确贴端：`refX = -(线宽 + 5.5)`

### 层级、同步与自动修复

- 业务节点记录 `parentId / order / level`，kind 为 head / group / bone
- 校验：父级存在、无环、根节点存在、深度限制、同级排序连续
- 保存与加载按连线同步层级，连线优先于旧 `data.parentId`
- 节点拖到目标端口松手改父级，成环或超限拦截
- 悬空连线自动回连到父级线体，并按排序分配锚点比例
- 加载后对 edge-to-edge 依赖链按父线先于子线收敛刷新视图

### 层级数据编辑

- 层级树弹窗：新增一级、新增子级、新增同级、删除、上移、下移、拖拽调级
- 结构操作即时应用到画布并写入一步历史
- 名称与重要标志保存时应用，不做结构性改动时不改写坐标与锚点

### 后端与存储

- 文档 CRUD：列表、新建、读取、保存、重命名、删除
- 主表 `hl_ygt` 存完整文档 JSON 与鱼头标题，明细表 `hl_ygtmx` 存业务层级
- 保存按线段解析父级，不依赖前端伪造的 `parentId`
- `positions` 为空时按 `hl_ygtmx` 自动重建布局
- token 开发脚本、日志滚动、配置示例与部署脚本齐备

### 导出与产物

- 导出 PNG、SVG、PDF、JSON，导入 JSON
- 画布左上角导出菜单与缩放控件
- 构建命令：`build.bat`、`build_frontend.bat`、`build_exe.bat`、`package.bat`

### 测试与工程化

- Playwright 页面级回归与后端数据校验脚本
- V1.0 全量 12 项前端回归、悬空回连回归、edge-to-edge 刷新回归通过，均为 `errors: []`
- Git 已接入：`main` 对应远端，回滚快照保留在 `.rollback/`

- 箭头线拖入自动吸附成真连线：已决定暂不实现，方案保留在 `docs/待考虑方案.md`
