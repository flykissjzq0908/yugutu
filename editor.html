操作说明

一、基础操作

  • 从左侧「组件」库把鱼头 / 鱼尾 / 鱼干 / 一级鱼刺 / 二级鱼刺 / 内容 / 文本框 / 图片拖到画布。
  • 从节点端口拖出连线到另一节点，即可建立连接。
  • 双击节点或连线上的文字进行编辑。
  • 选中元素后，用右侧「属性」面板修改颜色、字体、字号、背景、边框、线宽等样式。

二、鱼骨图结构

  • 鱼头 + 鱼尾 + 鱼干组成主轴。
  • 一级鱼刺连到鱼干；二级鱼刺（子原因）连到一级鱼刺的线体上。
  • 层级关系（父级 / 顺序 / 层级）自动保存，保存与导入时会自动校验。

三、连接点

  • Alt + 单击线体：在点击处添加一个空心连接点。
  • 双击鱼干：在鱼干上添加连接点。
  • 连接点可自由拖动，也可拖离线段成为自由连接点；靠近线段会自动吸附。
  • 预览与导出时会隐藏连接点并补齐线段空隙。

四、模板与画布

  • 顶部「模板」下拉：空骨架 / 经典六原因 / 根因分析。
  • 右下角缩放控件或 Ctrl+滚轮 缩放；空格+左键 平移画布。

五、预览与导出

  • 「预览」隐藏端口与连接点，只显示最终效果。
  • 支持导出 PNG / SVG / PDF / JSON，并可通过「导入 JSON」恢复。

六、快捷键

  • Ctrl+Z / Ctrl+Y 撤销 / 重做
  • Ctrl+C / V / X / D 复制 / 粘贴 / 剪切 / 快速复制
  • Ctrl+A 全选 · Ctrl+S 保存 · Delete 删除
  • 方向键 移动 1px · Shift+方向键 移动 10px
  • 空格+左键 平移 · Ctrl+= / Ctrl+- 缩放 · Ctrl+0 实际大小
提示：图片节点可在属性面板设为背景；「主题」按钮可切换浅色 / 深色。
